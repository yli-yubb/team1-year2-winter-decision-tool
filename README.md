# Team 1 Year 2 Winter Decision Tool

An English, client-side strategy comparison tool for Pork and Garlic Ice Cream Co. All amounts are virtual shekels.

## Run and deploy

Open index.html in a browser, or import this repository into Vercel. Choose Other, leave Build Command empty, and use the repository root. No API keys or external dependencies are required.

## Data basis

Year 1 winter was confirmed by Team 1. Spring sales of 55,000, summer sales of 100,000 and autumn sales of 70,000 are assumptions. The hypothetical summer loan is 60,000 over four seasons. These are scenario accounts, not full-year actual results.

Opening cash: 114,757; debt: 30,000; tax loss pool: 2,926; Year 1 net profit: 23,257. Machine 1 has four seasons left; Machine 5 has six. Year 2 prices are editable Year 1 estimates pending new rules. Storage benefits are not assumed.

## Features and checks

Compare two editable plans, their profit, cash flow, funding gaps, machine capacity and sales downside. The recommendation depends on entered sales, not guaranteed allocations. The same calculation engine verifies winter net profit of 4,171 and closing cash of 73,546. Run node test.mjs for the automated checks.

Inputs reset on reload. Review the model and test the live site before submitting both the GitHub and Vercel links beside your own name in the assignment spreadsheet.
